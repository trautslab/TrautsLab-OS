# Metodología de Codificación de Habilidades Deterministas

Las tareas diarias se estandarizan siguiendo 3 pasos:
1. **Identificación:** Grabar la rutina verbalmente o analizar logs de uso histórico.
2. **Definición de Salidas:** Estandarizar la estructura del archivo Markdown o JSON de resultado.
3. **Conversión a Automatización:** Configurar disparadores temporales (crons) para ejecución desatendida.
